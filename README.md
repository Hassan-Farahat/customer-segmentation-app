# 🎯 Customer Segmentation App

An interactive Unsupervised Machine Learning web app built with Python, Streamlit, and Scikit-Learn to categorize target markets into actionable customer personas using K-Means Clustering.

🚀 **[Live Demo](https://hassan-farahat-customer-segmentation-app-app-te4zlx.streamlit.app/)**

---

## ✨ Features

* **K-Means Clustering:** Automatically groups customers based on annual income levels and spending behavior.
* **Interactive Controls:** Dynamically re-cluster data by adjusting the $K$ cluster slider in real time.
* **Persona Summary Table:** Calculates average age, income, and spending scores across every cluster group.

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit** (Web App Framework)
* **Scikit-Learn** (K-Means Clustering & StandardScaler)
* **Plotly Express** (Interactive Visualizations)
* **Pandas & NumPy** (Data Processing)
